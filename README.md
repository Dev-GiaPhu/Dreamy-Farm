## 📌 Giới thiệu

**Dreamy Farm** là dự án game nông trại phát triển bằng **Unity 6 (Built-in Render Pipeline)**.  
Dù chưa có hệ thống trồng cây — cốt lõi của game nông trại — nhưng project tập trung vào lối chơi mô phỏng:

- 🎣 **Câu cá**
- 🌲 **Chặt cây**
- ⛏️ **Khai thác khoáng sản**

Dự án được hoàn thiện để nộp bài và làm nền tảng để phát triển tiếp thành một game nông trại hoàn chỉnh.

---

## 🧩 Tính năng hiện tại

### ✔ Đã hoàn thành
- Inventory system
- Item system cơ bản
- Chặt cây
- Đào khoáng sản
- Câu cá
- Map 2D hoàn thiện

### ❌ Chưa hoàn thiện / Đang phát triển
- Hệ thống trồng cây  
- Đặt khối (Building/Placing)
- Item drop (thả, bỏ vật phẩm)
